# Panel

The white container for every section: 1px border, radius-12, 24px padding, no shadow.

- Provide: a title (`panel-title`), optional meta on the right (`ink-faint`, source · date) or a control (SegmentedControl, outline button), an optional one-line description, then content.
- Panels stack with 22px between them; side-by-side pairs use a grid with minmax(330px, 1fr) and 16px gap.
