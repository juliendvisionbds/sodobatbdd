# BarChart

Monthly bars in a Panel, each labelled with its value in mono; bars above the average are navy, the rest navy-soft.

- Provide: one value per period, the average, and period labels. Heights are value / max × 100%.
- State the encoding in the panel meta ("barre foncée = au-dessus de la moyenne"). No gridlines, no legend.
- A bar is clickable and opens that month's detail view.
