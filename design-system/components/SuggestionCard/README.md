# SuggestionCard

A pre-written question a real user of the trade would ask, with the job it serves underneath; clicking sends it to the Chat.

- Provide: the question in the user's words (navy-deep 13.5/500) and a hint naming the intent ("Vérifier un prix sous-traitant", "Anticiper un avenant").
- 4–5 cards under a heading like "Questions d'un conducteur de travaux". Hover: navy border on navy-tint.
