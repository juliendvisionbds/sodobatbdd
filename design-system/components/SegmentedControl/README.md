# SegmentedControl

Two or three mutually exclusive modes of the same table (travaux normaux / supplémentaires), set in the panel header's right side.

- Provide: 2–3 short labels; the active one has `aria-pressed="true"` (white, navy text, border). Inactive text is ink-faint.
- Use it to switch the dataset of one panel. To switch whole views use Header tabs; to pick a period use Chip.
