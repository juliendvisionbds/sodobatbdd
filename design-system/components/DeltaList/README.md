# DeltaList

Ranked rows with a name, a before → after sub-line, and a signed euro delta (`delta` style) over its percentage; also the stat-row variant with one `figure` on the right.

- Provide: name, from, to, delta and pct already signed (+/-). Colour the delta `.vx-pos` or `.vx-neg`; the sign carries the meaning too.
- Rank by euros, not by percentage, and say so in the panel meta.
