# Button

Three weights: `.vx-btn` (navy fill, 15px/600, radius-9) for the single primary action, `.vx-btn-outline` (border, navy text, radius-8) for panel actions, `.vx-btn-ghost` (navy-line border, 12.5px) inside the banner only.

- Labels are verbs or exact outcomes: "Envoyer", "Afficher les 148", "Réduire à 15".
- One primary button per panel at most. Hover: primary → navy-deep; outline → navy border on navy-tint.
- Focus ring: 2px solid navy, 2px offset.
